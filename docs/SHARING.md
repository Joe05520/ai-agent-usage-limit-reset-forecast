## English introduction

AI Usage Sentinel is a free, open-source AI quota monitor with five-stage reminders and source-linked reset alerts. View remaining Codex allowance, regular reset times and unexpected increases from a native macOS menu bar or Windows/Linux beta tray client. Choose Professional, Intuitive (ring or battery) or Compact views. Account history stays local; aggregate analytics is optional and off by default.

Codex usage is read through the official local app-server. Claude Code requires a status-line bridge. Gemini and Grok currently use authorized local JSON/manual data. Public reset monitoring focuses on OpenAI/Codex. macOS builds are ad-hoc signed, not notarized; Windows/Linux are unsigned beta ports.
