統計如何解讀

  • 活動區間是一天內在相近、同額度週期的快照中觀察到 quota 下降的次數；只代表可觀察下限，並非 API 呼叫、提示詞、token 或花費。
  • 額度區間為當日最低觀察到的剩餘百分比區間：0–4、5–19、20–49、50–100%。不同供應商的 quota 無法直接比較。
  • 空白表示沒有足夠且同意分享的樣本，並不代表零使用者。隱藏的項目沒有「其他」殘餘總數可供相減推算。
  • 自願參與會有選擇偏差，回報可以被偽造；這些統計不能代表全球 AI 使用率或正式計費數據。

隱私與退出

每天最多一份摘要，含國家／地區、平台、版本、Agent、提醒階段數及使用變動次數區間。額度區間需獨立同意。不傳送帳號 ID、電子郵件、精確 quota、重置時間、提示詞、API token、cookies 或原始使用歷史。

Cloudflare 接收連線 IP 以估計國家及限制濫用；此專案的 D1 資料表不儲存 IP，Worker 請求記錄關閉。Cloudflare／GitHub 仍各自處理必要的連線資訊，並受其服務隱私政策約束。VPN、代理伺服器及 GeoIP 誤差會影響國家判定。

回報保存 35 天，排程自動刪除。App 設定可關閉後續分享，或選擇「刪除已分享回報並關閉」。公開圖表快取最多一小時；備份或平台復原資料的保留受 Cloudflare 規則約束。管理頁需要登入，只顯示彙整資料。
