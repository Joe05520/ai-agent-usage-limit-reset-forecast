04 / DIFFERENT AGENTS. HONEST DATA.

One place to look.

Choose a provider. The app shows one selected agent at a time and keeps its history local. Integration support depends on what each vendor officially exposes.

Codex

Automatic local read

Uses the official local app-server after Codex sign-in. Actual returned quota windows; no inference prompt.

Claude

Official status-line bridge

Imports quota-only JSON from Claude Code’s documented status line. Requires setup and a session publishing rate-limit data.

Gemini

Local JSON / manual

Accepts authorized local quota exports or manual values. No unsupported personal-usage endpoint is assumed.

Grok

Local JSON / manual

Accepts local quota evidence. API rate limits are not substituted for a SuperGrok subscription allowance.

Public reset monitoring currently focuses on OpenAI/Codex. Other agents’ news feeds are not yet integrated. Stale exports never become fresh usage.

A FEW THINGS TO KNOW.

Does it show every ChatGPT limit?

No. Live Codex usage contains only the windows the official provider returns. Other ChatGPT personal limits may be unavailable. Missing data is shown as unknown, never as an invented percentage.

Does an early signal mean I will get a reset?

No. A community report can be account-specific, mistaken or part of a limited rollout. Notifications include confidence and source links. Sentinel does not predict a next global-reset date.

Will notifications always appear immediately?

Detection runs on successful polls, normally every five minutes and after wake or opening the macOS menu. Sleep, Focus, Do Not Disturb and desktop notification support can delay or hide alerts.

Can I contribute or request another agent?

Yes. Provider adapters, translations, bug reports and platform testing are welcome. Link official documentation and keep private account data out of issues. Contribution guide ↗
